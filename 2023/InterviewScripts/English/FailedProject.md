# Failed Project

It's a developing send-back feature project for my current company's warehouse system, and for the warehouse management team, well, it was OK and releasable,
For me, it was still a bit strange. Normally, the system has to process 1,500 cases in a day,
But after the release, "20" of the 1500 cases were not processed, which is not a fatal problem for the system as a whole,
I felt bad when I checked the data, and discussed it with the leader afterwards,
and he said, "It's normal for the first release to have problems, so it's perfectly OK to make improvements in the future,"
which made me feel much better.
Of course, I was able to solve the problem with the improvement project afterwards, but what I learned through that project was
You can't make something perfect the first time, so you have to try things out to find out what works and what doesn't,
even if you fail you will learn something from that.
