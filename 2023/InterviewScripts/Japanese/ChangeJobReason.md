# 転職理由

現在の会社はもうすぐ３年間です。開発、見積もり、そしてライブコーディングもやっています。色々なことを体験できました。ただ、現在の会社のサービスの DAU は約 3 万人ほどで、それほど大規模ではないと感じています。そのため、もっと規模の大きいシステムを経験したいと考えています。

現在の会社のシステムは技術よりもビジネスロジックに重点を置いているため、私は技術の知識を向上させるために、より複雑な技術を持つシステムやプラットフォームで働く仕事を見つけたいと考えています。今の会社のシステムはたしかに色んな repository があるんですが、マイクローサービスではなく各 repository が同じデータベースと繋がりコード分けるだけで専用なサービスではないみたいです、基本的には各 repository の連携は普通の Http calling です、特に特別または複雑技術ではないです。

最近イベント駆動で実施するプロジェクトがあるんですけど、規模がまだちっちゃくてユーザ数が少なくて、少ないから想定外問題があまり発生しなくて、
問題解決とかチャレンジとかってあまりできてないです。

最近、インターネットを閲覧する際に、仮想通貨、ビットコインなどに関連するニュースが非常に多いと感じます。私はまた、この分野に興味をなんとなく持っており、ロバート・キヨサキさん自由 finance 本のを読んで、個人的にも、フィンテックの分野で挑戦してみたいと考えています。

また、私の現在の会社には日本人とベトナム人しかいません。異文化環境での仕事を試して、言語スキルを向上させ、さまざまな文化から学びたいとも考えています。

過去の 1 年間、成長はできてるんですけど期待より遅いです。たぶん原因は、現在の仕事に新しいチャレンジがちょっとすくないかもしれません。
それで、自分をチャレンジするために新しい環境を求めることにしました。すべてを最初からスタートのは難しいかもしれませんが、
これらの挑戦が私の個人的な成長に寄与すると信じています。あまりにも快適で安全な環境にとどまるよりも、新しい環境での方が成長できると考えています。

また、今の会社は優秀なエンジニアがあまりいなくて、だからこそ、
優秀エンジニアがいる環境に働きたくて
その優秀エンジニアから経験または問題解決の考え方を勉強したいと思ってます。
