# 長所と短所

私の強みには決断力と忍耐力があります。何かを達成したいとき、どんな大変でも、最後までやります。結果が完璧でなくても、少なくとも試み（こころみ）る勇気があり、自分にチャレンジし、望んだ通りでなくても何かを勉強になれると信じています。

例えばなんですけど、直近は貴社の課題解決した時に実は元々エージェントさんから課題をもらっていた時に「数時間かかれば解決できる」と言われたんですが、私が５時間立ってもまだ終わってなくて、メインの理由はちゃんと DDD アーキテクチャを適用と単体テストをちゃんと書いたので、思ったより時間かかったんですが、自分にとって一番良いな答えをやろうと思っていたから最後まで、単体テストとなんの環境でも構築できるために docker 化してから提出しました。

また、どんな大きなことでも小さなことでも、やる前にはちゃんと計画を立てます。具体的には、各段階で何をするか、どのような準備が必要か、どのようなリスクが発生する可能性があるかを考えます。

例として、転職のことなんですが。3 ヶ月前に転職のタイミングとその前に何をするかを計画しました。具体的には、10 月からは現職でこれまで勉強になった知識を振り返りました。11 月上旬には、LeetCode などのプラットフォームで実践的なコーディングを練習始めました。同時に、転職エージェントと協力して面接する企業を探しました。

私の弱点は、よく考えすぎる、時々単純な問題を必要以上に複雑にしてしまうことです。

実は今年の 8 月に、一人で宮崎の青島に旅行したことがあります。本当にきれいで、その風景を楽しんだ後、ホテルに戻ろうと思って、急に大雨が降り出しました。バスやタクシーに乗れなくて、道路には住居（じゅうきょ）も人もいなく、片側は山で、もう片方は海でした。私は本当に絶望して、「もうだめだ」「すべてが終わった」「これを救う方法はない」と思ってました。

しかし、突然気づいたのは冷静が必要であり、歩き続けないといけません。幸運なことに、雨の中を約 20 分歩いた後、親切な家族に出会い、彼らは車でホテルに連れてあげました。この経験を通じて、考えるだけで行動を起こさないとは意味もなく、結果もなく、結局その考えが全く意味ないと気づきました。したがって、この弱点を克服（こくふく）するために、これからは過度（かど）な考え込みではなく、できるだけ早く行動を出さないといけません。
