# Improve System

エンジニアとして、テストフレームワークを導入することで、システムを改善したいと考えています。例えば現在のシステムは単体テストが中心ですが、もし e2e テストを取り入れることで、システムの信頼性が向上すると思います。

API またはコードのコメント・ドキュメントが改善できれば全然やりたいと思って、会社のシステムに初めて触るエンジニアの目線から考えるとドキュメントが
必要となって、ドキュメントがなければシステムのコード沼に溺死 (できし)可能性もあるし、開発時に自分がやってることは正しいかどうかも不安になるし、ドキュメント
または仕様書があればその不安と悩みを解決できると思ってます。

システムは正常に動いてるのは全然いいけど、エラー発生すればどうやってエラーハンドリング、エラー管理するも大事だと思うエラーハンドリング framework ができれば
デバッグも早いし、暫定対応でも恒久対応でもすぐ効果が出てると思ってます。
